Linux 常用命令速查：从 cd 到 chmod

2026-11-08linux笔记

这是我在 Kali 虚拟机上练习 Linux 基础时的整理。命令不多，但都是从“完全不会”到“能自己干活”这一段的必需品。

一、先搞清楚自己在哪

Linux 的整个文件系统是一棵倒着的树，最顶端是 /（根目录）。没有 C 盘 D 盘，所有东西都挂在这一个 / 下面。

命令作用记忆
pwd显示当前所在目录print working directory
cd切换目录change directory
ls列出目录内容list

cd 的四种常用写法，区别是“出发点”不同：

cd /home/kali/web   # 绝对路径：从 / 开始，一定准确
cd web              # 相对路径：从当前位置往下走
cd ..               # 回上一级（两个点 = 父目录）
cd -                # 回到上一次待过的目录
cd                  # 不带参数 = 回家，等于 cd ~

容易错的地方：~/web 是对的，~web 会被当成“用户 web 的家目录”；迷路时一律用绝对路径。

二、创建、复制、移动、删除

mkdir lab1              # 建目录
mkdir -p a/b/c          # 一次建多层，-p = parent
touch note.txt          # 建空文件（也能更新文件时间）
cp note.txt backup.txt  # 复制
mv note.txt docs/       # 移动进目录
mv old.txt new.txt      # 改名（目标是“不存在的名字”时）
rm note.txt             # 删除文件
rm -r docs              # 删目录必须加 -r

rm 没有回收站，删掉就没了。新手阶段建议加 -i，删之前先问一句。

cp 和 mv 到底差在哪

cpmv
做什么复制一份，原件还在搬走，原件消失
Windows 对应复制 + 粘贴剪切 + 粘贴
目录要不要 -r要不要
目标已存在都会静默覆盖，加 -i 才会问

三、写入与查看

命令的输出默认去屏幕。用 > 可以改道写进文件：

echo "hello" > a.txt      # 覆盖写入（旧内容清空）
echo "world" >> a.txt     # 追加写入（旧内容保留）
seq 1 20 > nums.txt       # 生成 1~20，每行一个

> 会先清空文件，再执行命令。所以命令写错时，文件内容照样会没。这是最容易丢数据的一个符号，不确定时用 >>。

命令用途
cat 文件一次性全部输出，适合短文件
less 文件一屏一屏翻，q 退出，/关键词 搜索
head -5 文件前 5 行
tail -5 文件后 5 行
wc -l 文件数行数

四、管道：把小命令串成大工具

竖线 | 把左边命令的输出，直接交给右边命令处理。每个命令只做一件小事，管道负责组合——这是 Linux 的设计哲学。

cat nums.txt | grep 1      # 只留含字符"1"的行：1、10~19
ls | wc -l                 # 数当前目录有几个东西
seq 1 100 | grep 9 | head -3   # 生成 100 行 → 筛出含 9 的 → 只看前 3 行

注意 grep 匹配的是“字符片段”，不是数字。所以 grep 1 会把 10、11、19 都选出来——它们都含有字符 1。

五、vim：只能靠肌肉记忆的部分

vim 有“模式”，打开后直接敲键盘打不出字，因为你在普通模式。

vim hello.txt     # 打开（不存在会新建）

i                 # 进入插入模式，开始打字
Esc               # 回普通模式
:wq               # 保存并退出
:q!               # 不保存，强制退出

普通模式下几个够用的键：dd 删整行、u 撤销、x 删一个字符、gg 到开头、G 到结尾。

不要直接关终端窗口退出 vim，会留下 .swp 临时文件，下次打开会弹警告。按 D 删掉、R 恢复。

六、权限：那一串 rwxr-xr-x 怎么读

-rw-r--r-- 1 kali kali 51 Nov  3 11:51 nums.txt
│└┬┘└┬┘└┬┘
│ │  │  └── 其他人：r--（只读）
│ │  └───── 同组：r--
│ └──────── 所有者：rw-（读写）
└────────── 类型：- 文件 / d 目录 / l 链接

把 rwx 当三个开关，有就是 1，加起来就是数字权限：

权限数字常见用途
rwx7可执行程序、目录
rw-6普通文件的所有者
r-x5目录的同组/其他人
r--4只读
 
ls -l           # 看权限
chmod +x hi.sh  # 加执行权限
chmod 644 a.txt # 精确设置：所有者读写，其他人只读
chmod 755 dir   # 目录常用：自己可读写执行，其他人可读可进
umask           # 看新建文件的默认权限扣减（Kali 是 002）

一个直接结论：文件能不能当程序运行，看的不是后缀，而是有没有 x。

七、脚本与编译：两条让文件“能跑”的路

路一：脚本，交给解释器逐行执行

#!/bin/bash
echo "hello from my script"
chmod +x hi.sh
./hi.sh

第一行的 #!/bin/bash 叫 shebang，告诉内核“用 bash 来跑这个文件”。少了它、或写错成 #!/bin/bash/（多一个斜杠），就会报 not a directory。

路二：编译，翻译成机器码

#include <stdio.h>

int main() {
    printf("hello, world\n");
    return 0;
}
gcc hello.c -o hello    # 把源码编译成可执行文件
./hello                 # 运行

-o 只负责给输出文件起名，不写就是默认的 a.out。编译出的文件自带 x 权限，不需要再 chmod。

八、装软件

sudo apt update            # 刷新软件源目录（不是升级软件）
apt search 关键词           # 搜
sudo apt install 包名       # 装
sudo apt remove 包名        # 卸载
sudo apt autoremove        # 清理没人用的依赖

遇到 apt update 卡住、超时，第一反应是换国内镜像源（清华、阿里、中科大都有 kali 或 ubuntu 镜像），而不是怀疑网络断了。

九、报错怎么读

新手和熟手最大的差别不是记住多少命令，而是会不会读报错。

报错含义先查什么
command not found没有这个命令拼写、是否安装
No such file or directory文件不存在ls 确认名字和当前位置
Permission denied权限不足ls -l 看有没有 x / w
not a directory路径类型不对末尾是否多了斜杠
Is a directory把目录当文件操作cat 了目录

还有一句经验：Linux 成功时通常什么都不说，沉默即成功。只有出错才会开口。
